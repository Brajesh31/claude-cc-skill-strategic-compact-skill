# Cc Skill Strategic Compact

Development skill from everything-claude-code

## Overview

This repository preserves the AITMPL skill instructions and the published reference resources at their original relative paths.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-strategic-compact-skill.git ~/.claude/skills/cc-skill-strategic-compact
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-strategic-compact` as the destination.

## Usage

Claude Code can load the skill when a request matches its description. Invoke directly with `/cc-skill-strategic-compact` when needed.
